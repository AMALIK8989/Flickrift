How to Contribute

There are many ways to contribute:

Report bugs or suggest features

Improve documentation

Fix bugs

Add new features

We ❤️ contributions of all sizes, from tiny typo fixes to major features.

Reporting Issues

If you find a bug or have a feature request:

Check the Issues
 page to see if it’s already reported.

Open a new issue if it isn’t.

Include as much detail as possible:

Steps to reproduce the issue

Expected vs. actual behavior

Screenshots or logs (if applicable)

Submitting Pull Requests (PRs)

We love pull requests! Here’s how to make yours shine:

Fork the repo and clone it locally:

git clone https://github.com/your-username/flickrift.git
cd flickrift

Create a new branch for your changes:

git checkout -b feature/your-feature-name

Make your changes in the code.

Ensure your code passes all tests (if applicable).

Commit your changes with a clear message:

git commit -m "Add feature X to improve Y"

Push to your fork:

git push origin feature/your-feature-name

Open a pull request to the main branch of this repo.

Code Style

To keep FlickRift clean and consistent:

Follow existing code conventions

Write clear, readable code

Comment where necessary

Keep commits focused and meaningful

Community Guidelines

We’re building a friendly and inclusive community. Please:

Be respectful and considerate

Use clear, constructive language

No spam, harassment, or offensive content

Violations may result in being blocked from contributing.
